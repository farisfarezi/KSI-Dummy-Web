Web & AI Security Demo

Lab edukasi untuk menguji dua kelas risiko: prompt injection dan Cross-Site Scripting (XSS). Jalankan hanya di lingkungan pengujian milik sendiri.

Kerentanan 1 · Prompt Injection

Pemeriksa Instruksi AI

Simulasi berbasis kata kunci—bukan model AI sungguhan. Masukkan teks untuk melihat apakah pola instruksi mencurigakan terdeteksi.

Hasil pemeriksaan akan muncul di sini.

Pemeriksaan kata kunci dapat melewatkan variasi bahasa dan bukan pengganti pertahanan model.

Kerentanan 2 · Reflected XSS (simulasi aman)

Penguji Input Web

Masukkan teks atau payload uji. Demo ini menampilkan input sebagai teks biasa, sehingga HTML tidak dijalankan. Indikator menandai pola yang perlu ditinjau.

Hasil uji akan muncul di sini.

Mitigasi: textContent, bukan innerHTML. Ini simulasi deteksi, bukan eksploitasi XSS yang menjalankan kode.

Catatan laporan:

Demo ini memuat dua skenario risiko untuk pembelajaran. Prompt Injection adalah deteksi kata kunci, sedangkan XSS adalah simulasi input berisiko dengan output aman. Jangan melaporkan XSS sebagai kerentanan yang berhasil dieksploitasi; tuliskan sebagai skenario pengujian/risiko yang diuji secara aman.
